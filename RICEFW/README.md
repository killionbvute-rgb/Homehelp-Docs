# Homehelp RICEFW Documentation

## 1. Purpose

This folder contains the Homehelp RICEFW catalogue.

RICEFW is an enterprise approach for identifying and managing:

* Reports
* Interfaces
* Conversions
* Enhancements
* Forms
* Workflows

The purpose is to maintain visibility of custom capabilities throughout the platform lifecycle.

The guiding principle:

> Every custom capability should have a documented purpose and ownership.
