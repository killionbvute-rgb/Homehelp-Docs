# Homehelp Future Objects Catalogue

## 1. Introduction

The Future Objects Catalogue records planned capabilities that may be developed as Homehelp evolves.

These objects represent future institutional requirements.

The guiding principle:

> Future capability should be intentionally designed before implementation.

---

# 2. Future Object Categories

Future objects are classified as:

| Category    | Purpose                           |
| ----------- | --------------------------------- |
| Conversions | Data movement and migration       |
| Forms       | Documents and user-facing outputs |
| Extensions  | Additional capabilities           |
| Analytics   | Information and insights          |

---

# 3. Conversion Objects (C)

## C-001 Learner Data Import

## Purpose

Allow migration of existing learner information into Homehelp.

Potential sources:

* schools
* learning institutions
* existing databases

---

## C-002 Historical Learning Data Migration

## Purpose

Import previous learner progress information.

Potential data:

* assessments
* achievements
* learning history
