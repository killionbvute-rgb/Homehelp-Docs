# Homehelp Product Documentation

## 1. Purpose

This folder contains documentation describing the product vision, user experiences, and learner-focused capabilities of Homehelp.

The product layer translates institutional vision into meaningful experiences for:

* learners
* parents
* educators
* institutions

The guiding principle:

> Every product decision should improve learner understanding and outcomes.

---

# 2. Product Vision

Homehelp exists to create an intelligent learning companion that helps people understand and support every learner.

The product focuses on:

* personalised learning support
* learner discovery
* parent engagement
* trusted insights
