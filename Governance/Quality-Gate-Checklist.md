# Quality Gate Checklist

## Purpose

## Trigger Criteria
- Major architectural milestone
- Every N sprints (e.g. every 5 or 6 sprints)
- Before major release
- Before public beta
- Before production launch

## Assessment Areas

□ Domain Model
□ Architecture
□ ADR Alignment
□ Documentation
□ Governance
□ Sprint Execution
□ Code Quality
□ Technical Debt
□ Test Coverage
□ Repository Structure
□ Traceability
□ Security & Responsible AI
□ Release Readiness

## Decision Matrix

PASS
PASS WITH OBSERVATIONS
CONDITIONAL PASS
FAIL

## Required Outputs

- Quality Gate Report
- Improvement Actions (if any)
- Technical Debt Register Updates
- Governance Decision
