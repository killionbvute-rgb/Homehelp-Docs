# Homehelp AI Documentation

## 1. Purpose

This folder contains the documentation for Homehelp's artificial intelligence capabilities.

AI is a core capability of Homehelp, designed to help understand learners, generate insights, and support personalised learning experiences.

The guiding principle:

> AI should enhance understanding while preserving human responsibility.

---

# 2. AI Vision

Homehelp uses AI to support:

* learner understanding
* personalised support
* meaningful insights
* better educational decisions

AI is not designed to replace:

* parents
* educators
* human judgement
